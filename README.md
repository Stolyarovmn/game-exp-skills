# Skills: gauntlet-loop и gamemaker

Три агентских скилла для длинных автономных прогонов: агент строит, слепо сравнивает
результат с эталоном, закрывает **один** самый большой разрыв — и так много раундов
подряд, пока не победит планку или не кончится бюджет.

Всё состояние лежит на диске, поэтому прогон переживает `/clear`, автокомпакт и
перезапуск, а под `/loop` может крутиться всю ночь.

Это те самые три скилла из эксперимента на канале **Студия Игорь**: четыре игры
подряд — гонка, 2D-выживалка, космический симулятор и заход вообще без скиллов, —
2,29 млрд токенов и 60 часов работы агентов на Claude Opus 5 в Claude Code и
GPT 5.6 в Codex. Что из этого вышло и где скиллы честно провалились — разбор на
канале [@studioigor](https://www.youtube.com/@studioigor), а короткий пересказ
выводов — в разделе [«Что важно знать до запуска»](#что-важно-знать-до-запуска).

| Скилл | Для чего | Куда ставить |
|---|---|---|
| [`claude-code/gauntlet-loop`](claude-code/gauntlet-loop) | цикл полировки: довести любую работу до конкретного эталона | Claude Code |
| [`claude-code/gamemaker`](claude-code/gamemaker) | производственная лестница: от одной фразы до играбельной игры | Claude Code |
| [`codex/gauntlet-loop`](codex/gauntlet-loop) | тот же цикл, адаптированный под Codex (goal-механика, свой формат агентов) | Codex |

## Установка

Скилл — это папка. Скопируйте нужную в каталог скиллов своего агента:

```bash
# Claude Code
cp -R claude-code/gauntlet-loop ~/.claude/skills/
cp -R claude-code/gamemaker     ~/.claude/skills/

# Codex
cp -R codex/gauntlet-loop ~/.codex/skills/
```

Из зависимостей — только Python 3 (скрипты используют стандартную библиотеку).
Для скриншотов и headless-захвата понадобится то, чем вы снимаете свой проект:
Playwright/Puppeteer для веба, `godot --headless` для Godot, свой render-скрипт для
3D. Пути внутри скиллов рассчитаны на установку в `~/.claude/skills/<имя>` и
`~/.codex/skills/<имя>` — если положите в другое место, поправьте вызовы `python3` в
`SKILL.md`.

## gauntlet-loop

```
/gauntlet-loop <цель>              # начать прогон
/gauntlet-loop continue <slug>     # продолжить
/loop 25m /gauntlet-loop continue <slug>   # ночной прогон
```

Раунд устроен так: бесплатные ворота (сборка, типы, тесты, захват) → снимок артефакта
→ слепая пара A/B с эталоном → вердикт, записанный на диск **до** раскрытия ключа →
одна правка → лог. Один критик на раунд вместо веера субагентов, ротация линз вместо
панели, `commit-then-reveal` вместо честного слова.

Состояние прогона живёт в `.gauntlet/<slug>/`: `BAR.md` (планка), `RUBRIC.md` (линзы,
только ужесточать), `PIECES.md` (декомпозиция), `DELIVERABLE.md` (что человек держит в
руках в конце), `STATE.md` (журнал) и `rounds/NN/`.

Ключевая штука, ради которой всё затевалось: если на выходе должен быть **продукт**, а
не картинка, прогон не откроет ни одного полировочного раунда, пока не собран
вертикальный срез — от запуска до конца, целиком, пусть и уродливо. Полировка,
применённая к продукту, готовому на 40%, даёт красиво отполированные 40%.

## gamemaker

```
/gamemaker <амбиция>            # «клон Need for Speed», GDD, скриншоты, полуготовая игра
/gamemaker continue <slug>
```

Восемь ступеней с воротами: бриф → дизайн → harness → вертикальный срез → системы →
контент → полировка → релиз. Со ступени нельзя уйти, пока не выполнены критерии
приёмки, а объём зафиксирован в числах — контракт не даёт объявить победу на одной
трассе и одном враге. Три типа раунда (BUILD / FILL / POLISH), причём большинство
проверок решается автоматикой, а не агентом-критиком.

## codex/gauntlet-loop

Та же механика, тот же формат файлов; отличается платформенная часть — как заводится
задача, как задаются вопросы, куда складывается отчёт, плюс `agents/openai.yaml` и
`references/input-patterns.md`. Скрипты слепого сравнения совпадают с версией для
Claude Code байт в байт.

## Откуда это взялось

Метод — Gauntlet Loop Мэтта Шумера (somethingbig.ai): дай агенту референс, дроби
работу, никогда не позволяй агенту оценивать самого себя. Здесь он переделан под одно
жёсткое ограничение: **никакого fan-out субагентов** — веер агентов съедает лимиты
подписки за полчаса, а качество держат не параллельные критики, а инспектируемая
планка, судья, который не может подогнать вердикт, и запрет останавливаться на
«нормально».

## Что важно знать до запуска

Честно, по результатам прогонов:

- **Скилл-полировщик без чётких критериев сделает красивую картинку, а не игру.**
  Отсюда `DELIVERABLE.md`, вертикальный срез и facet-теги на кусках — без них
  все раунды уходят в кадр.
- **Метрика, вернувшая ноль, — это не «всё хорошо».** Критерий приёмки, который
  считает количество звуков в проекте, где звуковой подсистемы нет вообще, будет
  выполняться каждый раунд. Ворота должны падать, когда проверять нечего.
- **Прогон стоит времени и токенов.** Ночь под `/loop` — это десятки раундов и
  сотни миллионов токенов контекста; закладывайте бюджет раундов в `STATE.md`.
- **Перед ночным прогоном прогоните один полный раунд руками.** Первый же запрос
  разрешения останавливает цикл до утра.
